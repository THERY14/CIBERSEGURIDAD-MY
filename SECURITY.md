# Security Policy

CyberLabKit is an educational security project. Please use it only in environments you own or are explicitly authorized to test.

## Reporting a security issue

If you discover a security issue in the CyberLabKit code, open a private security report through GitHub when available. Do not publish sensitive details before a fix is available.

Never include credentials, access tokens, private customer data, or real-world target information in an issue or pull request.
