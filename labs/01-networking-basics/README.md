# Lab 01 — Networking Basics

## Goal
Understand the relationship between IP addresses, ports, DNS, TCP/UDP, and basic packet flow using an authorized local environment.

## Safety
Run this lab only against systems you own or an explicitly authorized training target. Do not scan public targets.

## Learning outcomes
- Identify local IPv4 configuration.
- Explain the role of DNS.
- Distinguish TCP from UDP.
- Identify listening services on your own machine.
- Capture and interpret a small amount of local traffic.

## Tasks
1. Record your machine's IP address and default gateway.
2. Resolve a documentation domain with a standard DNS tool.
3. Identify one TCP and one UDP example from documentation or a local service.
4. Inspect your own listening ports using the operating system's built-in tools.
5. Capture a short local traffic sample with Wireshark and identify DNS, TCP, or TLS traffic if present.
6. Write three observations and one question you still have.

## Evidence
Do not upload credentials, personal data, or private network details. Use redacted screenshots or sanitized notes.

## Challenge
Explain, in your own words, what happens from entering a website address in a browser until an HTTPS connection is established. Include DNS, TCP, and TLS.
