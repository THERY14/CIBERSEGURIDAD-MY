# Lab 02 — Linux Basics and Hardening

## Goal
Build confidence with Linux users, permissions, processes, services, logs, and basic defensive checks.

## Safety
Use a disposable VM or another system you own. Do not apply hardening changes to production systems without authorization and a rollback plan.

## Learning outcomes
- Navigate the filesystem from the shell.
- Explain Unix permissions.
- Inspect processes and services.
- Locate relevant system logs.
- Identify basic hardening opportunities.

## Tasks
1. Create a non-root practice user in a disposable VM.
2. Create a directory with intentionally different permissions and explain the result.
3. Inspect running processes and identify three you can explain.
4. Identify active services and explain their purpose.
5. Locate authentication or system logs appropriate to your distribution.
6. Write a short hardening checklist for a fresh learning VM.

## Evidence
Sanitize usernames, hostnames, IP addresses, tokens, and other sensitive information before committing evidence.

## Challenge
A service is running that the lab owner does not recognize. Describe a safe investigation workflow before disabling anything.
