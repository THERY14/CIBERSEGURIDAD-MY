# CyberLabKit branding

## Name
**CyberLabKit**

## Tagline
**Build. Practice. Prove.**

## Short description
A safe, open-source toolkit for building, validating, and documenting cybersecurity learning labs.

## Visual direction
Use a simple technical identity built around a shield, terminal prompt, and lab grid. Prefer high-contrast layouts that remain readable in GitHub, documentation sites, and terminal output.

## Voice
- Practical
- Honest
- Beginner-friendly without being simplistic
- Security-conscious
- Evidence-driven
- Community-oriented

## Naming
Use `CyberLabKit` for the project and `cyberlabkit` for the Python package and CLI.
