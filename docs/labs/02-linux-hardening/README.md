# Lab 02 — Linux hardening basics

**Level:** beginner

## Objective

Inspect a Linux learning VM and identify simple hardening opportunities.

## Authorized scope

Use only a Linux VM or host you own/control.

## Tasks

1. Inventory users, running services, listening ports, and update status.
2. Identify at least three unnecessary or risky configurations.
3. Propose a mitigation for each finding.
4. Apply one reversible hardening change.
5. Re-run the relevant check and document before/after results.

## Evidence

Keep sanitized command output and screenshots in `evidence/`.

## Success criteria

The learner can explain why each finding matters, choose an appropriate mitigation, and verify the result without breaking the lab.
