# Lab 01 — Networking fundamentals

**Level:** beginner

## Objective

Understand basic host/network information and document observations without scanning or attacking external systems.

## Authorized scope

Use your own computer, a private virtual network, or an explicitly authorized training environment.

## Tasks

1. Identify your local IP address and default gateway.
2. Identify the DNS resolver configured on the learning machine.
3. Explain the difference between a private IP, public IP, gateway, and DNS resolver.
4. Capture a small amount of your own normal DNS/HTTP(S) traffic with Wireshark if available.
5. Record three observations in `notes/`.

## Evidence

Save screenshots or sanitized text output in `evidence/`. Do not include public credentials, tokens, or private personal data.

## Success criteria

You can explain what each observed network endpoint does and can reproduce the observations on your own lab.
